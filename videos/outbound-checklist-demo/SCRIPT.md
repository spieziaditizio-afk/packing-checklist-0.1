# SCRIPT — outbound-checklist-demo

**Voice:** Kokoro `am_michael` (offline; no HeyGen sign-in this run)
**Voice settings:** default
**Voice direction:** Calm, competent, plainspoken — a warehouse ops voice, not a SaaS pitchman. No hype words, no exclamation energy. Confident pauses between phrases.

---

## Line 1 — Hook (Frame 1)

**Time:** 0.0 – ~7s
**Delivery:** Flat, a little clipped — let the two phrases land as separate beats.

    One box too many on a pallet. Nobody catches it on the floor — it rides all the way to the truck before anyone knows.

## Line 2 — Meet Outbound Checklist (Frame 2)

**Time:** ~7 – ~14s
**Delivery:** Settles into a steady, explanatory register as the app appears.

    This is Outbound Checklist — Arrow Electronics' pre-shipment verification tool, built to run scan by scan, right where the pallets get staged.

## Line 3 — Scan the pallet (Frame 3)

**Time:** ~14 – ~24s
**Delivery:** Concrete instructions, then the payoff phrase — matched to each scan landing on screen.

    Scan the Pick Label PN, then each box's quantity. Every valid scan flashes green and beeps the instant it lands.

## Line 4 — It keeps moving with you (Frame 4)

**Time:** ~24 – ~34s
**Delivery:** Picks up pace slightly — this beat is about momentum.

    Finish one pallet, and the app jumps straight to the next one's tab and scan field — an operator can work through a whole delivery without ever touching the mouse.

## Line 5 — It stops before the truck does (Frame 5)

**Time:** ~34 – ~46s
**Delivery:** The climax line. Slow down on "it doesn't ride along quietly" and land "it stops" as its own beat — hold half a second before the rest.

    Scan one box too many, and it doesn't ride along quietly. It stops — right there, so the operator can find the double scan before it reaches the truck.

## Line 6 — One clear answer (Frame 6)

**Time:** ~46 – ~55s
**Delivery:** Relief after the tension of Line 5 — warmer, resolved.

    Every pallet resolves to one clear answer — a green MATCH badge — and a print-ready report, ready for the paper trail.

## Line 7 — No server, no install (Frame 7)

**Time:** ~55 – ~64s
**Delivery:** Plain and matter-of-fact — this is a practical claim, not a boast.

    No server, no database, nothing to deploy. It's one HTML file — double-click it and start scanning in seconds.

## Line 8 — Outro (Frame 8)

**Time:** ~64 – ~70s
**Delivery:** Slow down for the close. Even, declarative, a period at the end of each sentence.

    Outbound Checklist — every pallet, every box, verified before it ever leaves the dock.
